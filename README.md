# TeamMate 🎮

## 📌 Project Overview
**TeamMate** is an intelligent team formation system designed specifically for university gaming clubs. Manually managing player rosters and creating balanced squads can be tedious and prone to bias. This application automates and optimizes that process, ensuring teams are intelligently grouped based on player skills, preferred roles, and compatibility to maintain a competitive edge.

## 🚀 Key Features
* **Intelligent Matchmaking:** Algorithmic team generation to ensure balanced and synergistic squads.
* **Player Profiling:** Manages individual player statistics, gaming roles, and availability.
* **Roster Management:** Streamlines the administrative tasks for gaming club organizers and team captains.
* **Scalable Architecture:** Built with clear Object-Oriented principles to easily accommodate new games or club requirements.

## 🛠️ Tech Stack
* **Core Language:** Java
* **Design & Documentation:** UML (Unified Modeling Language)
